# Third-party material

TannX OS is written from scratch: the kernel in GNU assembler, the
userland in freestanding C, with no libraries linked in. The following
data of external origin is included.

## Console font glyphs (`user/font8x16.h`, kernel `font8x16` table)

The 8x16 bitmap glyphs used for the framebuffer console were extracted
from the **Lat15-Fixed16** console font shipped with Debian's
`console-setup` package (the "Fixed" family of console fonts). Those
font bitmaps are in the public domain. The glyph table is pure data; the
rendering code around it is TannX OS's own.

## Lato font (logo artwork in `logo/*.inc`)

The "TannX" wordmark bitmaps in `logo/` were pre-rendered with
**Lato** by Lukasz Dziedzic (Copyright (c) 2010-2014 by tyPoland Lukasz
Dziedzic), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). No font file is redistributed; only
rasterised artwork generated by `logo/mkgui.py` / `logo/mklogo.py`.

## Name and logo

"TannX", "TannX OS" and the fir-tree logo (`logo/tbm-tree.png`
and the bitmaps derived from it) are trademarks of Tannenbaum Media. They
are NOT licensed under the GPL. Forks are welcome under a different name
and without the logo.

## Everything else

- The baseline JPEG decoder (`user/jpeg.c`, host test `test-jpeg.sh`) was
  written for TannX OS from the ITU-T T.81 specification and is covered by
  the project license (GPL-3.0-or-later).
- Build and test tooling (GNU binutils, gcc for the ring-3 userland,
  QEMU, OVMF, mtools, dosfstools, python3, curl, netcat, tcpdump,
  ImageMagick) is used as installed on the host and is not redistributed
  in this repository.

If you believe something in this repository is derived from a work not
listed here, please open an issue.
